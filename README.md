# AIL (Archive Image Library) Format

AIL — высокопроизводительный формат архивации изображений, оптимизированный для быстрого просмотра, экономного использования памяти и защиты данных.

## Особенности формата

- **Мгновенный просмотр**: встроенная секция превью (thumbnails) позволяет галерее отображать содержимое без распаковки основных данных.
- **Асинхронная загрузка**: декодирование изображений и создание текстур вынесено в фоновые потоки.
- **Эффективное сжатие**: поддержка алгоритмов Zstd и LZ4.
- **Защита данных**: прозрачное шифрование AES-256-GCM.

## Структура файла (.ail v2)

Файл имеет строго детерминированную бинарную структуру. Все числовые значения записываются в формате **Little-Endian**.

### 1. Header (32 байта)

| Смещение | Размер | Тип | Описание |
|----------|--------|-----|----------|
| 0 | 4 | [u8; 4] | Магическое число `AIL!` |
| 4 | 4 | u32 | Версия формата (текущая: 2) |
| 8 | 1 | u8 | Флаг шифрования (0 — нет, 1 — AES-256-GCM) |
| 9 | 3 | [u8; 3] | Зарезервировано |
| 12 | 4 | u32 | Количество записей в архиве |
| 16 | 8 | u64 | Смещение секции превью |
| 24 | 8 | u64 | Размер секции превью |

### 2. Thumbnail Section

- **Thumbnail Header (20 байт)**: width, height, compression, reserved, data_size
- **Thumbnail Data**: JPEG, сжатый Zstd и зашифрованный AES-GCM

### 3. Index Section

Последовательность записей **AilEntry**: имя (null-terminated UTF-8), тип записи, тип сжатия, размеры, смещение, MD5 хеш.

### 4. Data Section

Для каждого блока: Nonce (12 байт) + зашифрованный payload + auth tag (16 байт).

## Использование

1. Поместите изображения в папку или используйте ZIP/RAR/7z архив.
2. Используйте встроенный кодировщик для создания `.ail` файла.
3. Откройте папку с `.ail` файлами в галерее для просмотра.

## Сборка

```bash
cargo build --release
```

### Cargo features

| Feature | Описание |
|---------|----------|
| `gui` (default) | egui/eframe просмотрщик |
| `ffmpeg` (default) | поддержка видео через FFmpeg |
| `unrar` (default) | чтение RAR-архивов |

Минимальная сборка без GUI:

```bash
cargo build --no-default-features
```

На Windows требуются системные библиотеки FFmpeg (см. `build.rs`). Ключ шифрования генерируется автоматически в `key.bin`.

### Отладочные логи

По умолчанию включены консольный вывод и файл `ail_debug.log` рядом с `ArchiveUtils.exe`.

Отключить: `set AIL_LOG=0` перед запуском.

Логируются операции с видео: открытие, декодирование кадров, кодирование, FFmpeg init.
